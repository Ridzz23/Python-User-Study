## Shell Command Documentation

### grep

The `grep` command searches for text patterns in files or command output.

Man page:

https://man7.org/linux/man-pages/man1/grep.1.html

---

### mv

The `mv` command moves or renames files and directories.

Man page:

https://man7.org/linux/man-pages/man1/mv.1.html

---

### mkdir

The `mkdir` command creates one or more new directories.

Man page:

https://man7.org/linux/man-pages/man1/mkdir.1.html

---

### cd

The `cd` command changes the current working directory in the shell environment.

Man page:

https://man7.org/linux/man-pages/man1/cd.1p.html

---

### find

The command `find ` searches for files in a directory hierarchy.

Man page:

https://www.man7.org/linux/man-pages/man1/find.1.html

---

### echo

The command `echo` displays a line of text.

Man page:

https://man7.org/linux/man-pages/man1/echo.1.html

---

### sort

The command `sort` sorts lines of text files.

Man page:

https://man7.org/linux/man-pages/man1/sort.1.html

---

### ls

The command `ls` lists directory contents.

Man page:

https://man7.org/linux/man-pages/man1/ls.1.html
