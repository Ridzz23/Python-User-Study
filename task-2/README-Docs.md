### find

The `find` command searches for files and directories in a directory hierarchy based on user-defined criteria, such as name, size, or modification time.

**Example using `-name`:**

To search for a file named `config.json` starting from the current directory:

```bash
find . -name "config.json"
```

To search for all `.txt` files (using wildcards):

```bash
find /path/to/search -name "*.txt"
```

Man page:

https://man7.org/linux/man-pages/man1/find.1.html
