# General Task Instructions

1. Task specific documentation has been provided in `README-Docs.md` in each task folder.
2. You are also free to refer to anythink within these sites:
    - Linux man pages: https://man7.org/linux/man-pages/
    - Python 3.13 Docs: https://docs.python.org/3.13/ 
3. Please DO NOT google search anything else
4. Please DO NOT use AI or LLMs to complete the tasks.
5. If you encounter an issue or are unsure about anything, raise your hand and wait for assistance.
6. After each task (not TODO), wait for PI approval before moving on.
7. Please use the validate script as shown below to check if you have completed each TODO. You can run this on the command line:

```bash
./validate.sh
```
This will automatically run your script and validate it. 

8. If you want to run only your script you would run this in the command line:

```bash
PyPepper <file_name>
```

For example:
```bash
PyPepper pepper_template.py
```
This is optional and not required. For the most part you would run the validate script to check your code.

# Task 1 - Servers

### Objective

Complete the implementation in `python_template.py` to collect server stats and generate an incident report. Ideally you will write some lines of code in this task. 

## Instructions
1. Navigate to the `task-1` directory
2. Open `README-Docs.md` to review documentation for commands that may be useful for this task.
3. Open `python_template.py` and complete the 3 TODOs. Do not modify any helper functions. Begin coding from the `START CODING FROM HERE` comment.
4. It is recommended to solve them in chronological order since each one builds on the previous one. 
5. After you complete a task please run the validate script to check which will indicate if you have completed each TODO correctly
   - If it indicates that your solution is wrong you are allowed to (and recommended) to try again until you get it right
   - Please run `./validate.sh` within the `task-1` directory

6. Once you are done with all TODOs and they are correct (or if you are done and want to move onto the next task regardless) **please raise your hand and wait for the PI to come over**.


> **⚠️ Do not begin Task 2. Raise your hand and wait for approval from the PI.**
